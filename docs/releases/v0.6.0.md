FerryDock 0.6.0 adds live container resource charts and Compose rebuild controls.

### Changes

- See CPU usage and memory used/limit directly in the container list.
- Monitor the selected container with smooth CPU and memory charts. Labelled
  axes show CPU percentage and memory in MiB; hover for measured values and
  sample age. Recent history spans the chart width, up to two minutes.
- Read configured CPU quotas and memory limits separately from usage. Containers
  without a memory limit identify Docker capacity explicitly, and stopped,
  disconnected, unavailable, or stale readings are labelled.
- Rebuild a Compose project's images and restart its services from the project
  toolbar or menu. Follow build output and progress, and return to retained
  results and errors after switching views.
- Read container details in a roomier header, with resource charts remaining
  visible above Logs, Terminal, and Inspect.

### Downloads

Linux x86-64 downloads include an AppImage, Debian package, and tar.gz archive.
Apple Silicon Macs running macOS 15 or newer can use the DMG preview. Mac builds
remain ad hoc signed and not notarized. All downloads are covered by
`SHA256SUMS`.

See the [user guide](https://github.com/pelletiermaxime/ferrydock#readme) for
installation, keyboard shortcuts, requirements, and troubleshooting.
