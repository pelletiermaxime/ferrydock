FerryDock 0.8.0 adds a Volumes workspace and deeper image inspection, with
more ways to browse and clean up local Docker resources.

### Changes

- Manage local volumes in a dedicated workspace. Search by name, driver, or
  Compose project, sort the inventory, inspect configuration, and see which
  running or stopped containers use each volume. Open referenced containers
  directly from the volume details.
- Gather volume sizes on demand and sort by disk usage in MiB. Measurements
  remain available through refreshes and workspace changes, with explicit
  loading, unavailable-value, and error feedback.
- Ctrl-click to select multiple volumes and review single or bulk removal,
  including selections hidden by search. Volumes in use are preserved;
  completion notifications report successes and failures. Prune unused
  anonymous volumes or all unused volumes after reviewing the confirmation.
- Explore image build history and read-only image JSON in new History and
  Inspect tabs. Resize history columns, choose which metadata to show, search
  commands, and open a full instruction for reading, searching, or copying.
- Prune untagged images or all unused images from the Images workspace.
  Images referenced by running or stopped containers are preserved, and
  completion notifications report reclaimed space when Docker provides it.
- Read relative creation ages for images and volumes, while exact UTC creation
  dates remain available in their details.
- Navigate long container, image, and volume lists with visible, draggable
  scrollbars that preserve selection.

### Downloads

Linux x86-64 downloads include an AppImage, Debian package, and tar.gz archive.
Apple Silicon Macs running macOS 15 or newer can use the DMG preview. Mac builds
remain ad hoc signed and not notarized. All downloads are covered by
`SHA256SUMS`.

See the [user guide](https://github.com/pelletiermaxime/ferrydock#readme) for
installation, keyboard shortcuts, requirements, and troubleshooting.
