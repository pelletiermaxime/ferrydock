FerryDock 0.15.1 keeps container terminals connected when you move between
containers.

### Fixes

- Switching containers preserves each open shell, its output, and the running
  or completed state of its favorite command. Return to the container to resume
  using the same terminal, including long-running commands such as `gulp watch`.
- Opening or disconnecting another container's shell leaves your existing
  sessions connected. Up to six container shells stay open; disconnect a shell
  to free a slot without interrupting another active session.

### Downloads

- **Linux x86-64:** AppImage, Debian package and tar.gz archive.
- **Windows x64:** portable ZIP preview.
- **Apple Silicon macOS 15+:** DMG preview, ad hoc signed and not notarized.

All downloads are covered by `SHA256SUMS`. See the
[user guide](https://github.com/pelletiermaxime/ferrydock#readme) for installation
and requirements.
