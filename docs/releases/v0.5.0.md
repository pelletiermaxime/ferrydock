FerryDock 0.5.0 makes container logs easier to read with matching source colours
and fewer repeated timestamps.

### Changes

- Identify containers at a glance with coloured source labels in combined project
  logs and matching markers beside their names in the container list. Colours
  remain stable during the session, including after filtering or recreating a
  container with the same name, and stay readable in light and dark themes.
- Remove Docker's additional high-precision timestamp prefix from displayed and
  copied logs. Dates written by your application and its ANSI colours and styles
  are preserved.

### Install

Download `ferrydock-0.5.0-linux-x86_64.AppImage`, make it executable, and launch
it from your desktop session:

```sh
chmod +x ferrydock-0.5.0-linux-x86_64.AppImage
./ferrydock-0.5.0-linux-x86_64.AppImage
```

If FUSE mounting is unavailable, add `--appimage-extract-and-run`.

On Ubuntu 24.04 or a compatible Debian-based distribution, you can instead
install `ferrydock_0.5.0_amd64.deb`:

```sh
sudo apt install ./ferrydock_0.5.0_amd64.deb
```

Alternatively, extract `ferrydock-0.5.0-linux-x86_64.tar.gz` and run `./ferrydock`
from the extracted directory. Its `INSTALL.txt` lists runtime dependencies.
Use the included `SHA256SUMS` to verify any of the three downloads.

### Requirements

- Linux x86-64 with glibc 2.39 or newer and a Wayland or X11/XWayland desktop.
- An installed font, the desktop's Wayland libraries, and a working Vulkan/EGL
  graphics driver stack.
- A local Docker daemon accessible by your user account. Docker Compose v2 is
  required for project controls.

See the [user guide](https://github.com/pelletiermaxime/ferrydock#readme) for
setup, keyboard shortcuts and troubleshooting.
