FerryDock 0.15.3 updates its dependencies, including GPUI Kit, GPUI Fast, and
Tokio.

### Changes

- In a local Linux release benchmark on native COSMIC Wayland, median
  resident memory fell from 136.7 MiB to 133.6 MiB while following live logs
  from ten containers. Idle memory was within run-to-run variation.
- The container log toolbar keeps its compact spacing with the updated UI
  toolkit.
- The developer log benchmark supports native COSMIC Wayland window capture
  and keyboard input.

### Downloads

- **Linux x86-64** offers an AppImage, a Debian package, and a tar.gz archive.
- **Windows x64** offers a portable ZIP preview.
- **Apple Silicon macOS 15+** offers an ad hoc signed DMG preview without
  notarization.

All downloads are covered by `SHA256SUMS`. See the
[user guide](https://github.com/pelletiermaxime/ferrydock#readme) for installation
and requirements.
