FerryDock 0.10.0 makes Compose projects easier to identify, organize, and clean up.

### Changes

- See the Compose file path beneath each project name. Hover it to read all
  files in override order and, when verified locally, the linked Git worktree
  root. Linked checkouts show a **Git worktree** tag.
- Accessible Compose files and labeled environment files are associated
  automatically, making project controls available immediately. Use
  **Configuration** to add profiles or customize the invocation; saved choices
  take precedence over automatic discovery.
- Choose **More → Stop & cleanup…** to stop and remove project containers,
  including stopped services and orphans, and remove the project's networks.
  Review the containers and choose whether to permanently delete project volumes
  and remove Compose-generated local images. External resources, bind-mounted
  files, explicitly tagged images, and build cache are preserved. Successful
  cleanup removes the saved association and empty project heading; progress and
  errors appear in **Operations**.
- Collapse or expand bordered Compose groups and standalone containers with
  their chevrons. Folding preserves the current detail panel and session.
  Search temporarily reveals matching containers, and clearing it restores the
  folds. Keyboard navigation skips folded rows.

**Stop** continues to retain containers and data for starting the project again.
With **Running only** enabled, stopped container rows are hidden while their
project heading remains available.

### Downloads

Linux x86-64 downloads include an AppImage, Debian package, and tar.gz archive.
Apple Silicon Macs running macOS 15 or newer can use the DMG preview. Mac builds
remain ad hoc signed and not notarized. All downloads are covered by
`SHA256SUMS`.

See the [user guide](https://github.com/pelletiermaxime/ferrydock#readme) for
installation, keyboard shortcuts, requirements, and troubleshooting.
