FerryDock 0.4.0 adds appearance settings and resource menus, with more convenient
filtering and clearer logs across themes.

### Changes

- Choose FerryDock, Dark, or Light in Settings. Theme changes apply immediately
  and are remembered on this computer. Use **Use FerryDock theme** to restore
  the original charcoal and mint appearance.
- Open or close appearance settings with **Ctrl+,**, including from an active
  terminal session. Changing themes preserves your selected resource and shell
  session.
- Right-click a container or Compose project, or open **More** in its detail
  toolbar, to access navigation, configuration, and available actions.
- Filter combined project logs with a searchable service picker. Use the
  **Running only** checkbox to show or hide stopped containers, and choose Bash
  or sh with the shell selector.
- Keep ANSI log and terminal colours readable on light backgrounds while
  retaining the original palette on dark surfaces.
- Handle malformed UTF-8 log output more efficiently while preserving characters
  split across stream chunks. Initial container log history over 32 MiB now
  reports an explicit error to prevent excessive memory use.

### Install

Download `ferrydock-0.4.0-linux-x86_64.AppImage`, make it executable, and launch
it from your desktop session:

```sh
chmod +x ferrydock-0.4.0-linux-x86_64.AppImage
./ferrydock-0.4.0-linux-x86_64.AppImage
```

If FUSE mounting is unavailable, add `--appimage-extract-and-run`.

On Ubuntu 24.04 or a compatible Debian-based distribution, you can instead
install `ferrydock_0.4.0_amd64.deb`:

```sh
sudo apt install ./ferrydock_0.4.0_amd64.deb
```

Alternatively, extract `ferrydock-0.4.0-linux-x86_64.tar.gz` and run `./ferrydock`
from the extracted directory. Its `INSTALL.txt` lists runtime dependencies.
Use the included `SHA256SUMS` to verify any of the three downloads.

### Requirements and limits

- Linux x86-64 with glibc 2.39 or newer and a Wayland or X11/XWayland desktop.
- An installed font and a working Vulkan/EGL graphics driver stack.
- An existing local Docker daemon accessible by your user account. Rootless
  Docker through a local Unix socket is supported; SSH and TCP/TLS connections
  remain unsupported.
- Docker Compose v2 and locally available configuration files are required for
  project controls. Start creates or starts services without building images.
- Log views support colours and basic progress editing. Use the Terminal tab
  for interactive applications that require a full terminal screen.

See the [user guide](https://github.com/pelletiermaxime/ferrydock#readme) for
setup, keyboard shortcuts and troubleshooting.
