FerryDock 0.15.0 improves image workspace sizing and terminal navigation, and adds
experimental hot reload for development.

### Workspace improvements

- Double-click an image-history column divider to fit the column to its contents.
  Your selected history row stays selected, and long build commands remain
  available in the full-command view.
- The image-analysis layer sidebar keeps its chosen width when the window
  resizes. Drag its divider to adjust it manually.
- Returning from Inspect to a Terminal tab without an open shell now restores
  keyboard focus, so Enter opens the shell as expected.

### Development hot reload

- Developers can try experimental Rust UI hot reload with the updated GPUI
  engine. See the [development guide](https://github.com/pelletiermaxime/ferrydock/blob/v0.15.0/docs/development.md)
  for the launcher, required tooling, and patch limitations. Hot reload is
  optional and does not run in release builds.

### Downloads

- **Linux x86-64:** AppImage, Debian package and tar.gz archive.
- **Windows x64:** portable ZIP preview.
- **Apple Silicon macOS 15+:** DMG preview, ad hoc signed and not notarized.

All downloads are covered by `SHA256SUMS`. See the
[user guide](https://github.com/pelletiermaxime/ferrydock#readme) for installation
and requirements.
