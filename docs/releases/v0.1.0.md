FerryDock's first release brings container browsing, live logs, and an embedded
terminal together in a native Linux desktop app.

### Features

- Browse Docker Compose projects and standalone containers.
- Search by container name, image, service, or project.
- Follow timestamped logs, pause scrolling, and copy output.
- Open Bash or sh inside a running container, with colors, scrollback,
  copy/paste, and full-screen terminal programs.
- Start, stop, and restart individual containers.
- Inspect full container configuration as JSON.
- Use native Wayland or X11/XWayland on your Linux desktop.

### Install

Download `ferrydock_0.1.0_amd64.deb` for Ubuntu 24.04 or a compatible Debian-based
distribution, then install it with:

```sh
sudo apt install ./ferrydock_0.1.0_amd64.deb
```

Launch **FerryDock** from your applications menu or run `ferrydock` from a desktop
terminal.

Alternatively, extract `ferrydock-0.1.0-linux-x86_64.tar.gz` and run `./ferrydock`
from the extracted directory. See its `INSTALL.txt` for runtime dependencies.
`SHA256SUMS` contains checksums for both downloads.

### Requirements and limits

- Linux x86-64, glibc 2.39 or newer, a working graphics driver, and Wayland or X11/XWayland.
- An existing local Docker daemon accessible by your user account, including
  rootless Docker through a local Unix socket.
- SSH and TCP/TLS Docker connections are not supported in this release.
- Compose project-wide controls, rebuilding, and network or volume management
  are planned; this version controls individual containers.
- The terminal does not yet support IME composition or mouse input for terminal
  applications.

See the [user guide](https://github.com/pelletiermaxime/ferrydock#readme) for
keyboard shortcuts and troubleshooting.
