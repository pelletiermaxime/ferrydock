FerryDock 0.2.1 fixes ANSI rendering in container logs, combined Compose logs,
and Compose operation output.

### Changes

- See the colours and text styles emitted by your services instead of literal
  ANSI escape codes. Standard, bright, 256-colour and RGB output is supported.
- Keep each container's colours independent in combined project logs, with
  readable service labels and Docker timestamps.
- Display basic progress updates that use carriage returns, backspaces or
  erase-line sequences, while preserving Docker's timestamp prefix.
- Copy readable logs without embedded colour codes.
- Keep busy logs responsive with cached styling and visible-row rendering.

### Install

Download `ferrydock-0.2.1-linux-x86_64.AppImage`, make it executable, and launch
it from your desktop session:

```sh
chmod +x ferrydock-0.2.1-linux-x86_64.AppImage
./ferrydock-0.2.1-linux-x86_64.AppImage
```

If FUSE mounting is unavailable, add `--appimage-extract-and-run`.

On Ubuntu 24.04 or a compatible Debian-based distribution, you can instead
install `ferrydock_0.2.1_amd64.deb`:

```sh
sudo apt install ./ferrydock_0.2.1_amd64.deb
```

Alternatively, extract `ferrydock-0.2.1-linux-x86_64.tar.gz` and run `./ferrydock`
from the extracted directory. Its `INSTALL.txt` lists runtime dependencies.
Use the included `SHA256SUMS` to verify any of the three downloads.

### Requirements and limits

- Linux x86-64 with glibc 2.39 or newer and a Wayland or X11/XWayland desktop.
- An installed font and a working Vulkan/EGL graphics driver stack.
- An existing local Docker daemon accessible by your user account. Rootless
  Docker through a local Unix socket is supported; SSH and TCP/TLS connections
  remain unsupported.
- Docker Compose v2 and locally available configuration files are required for
  project controls. Start creates or starts services without building images.
- Log views support colours and basic progress editing. Use the Terminal tab
  for interactive applications that require a full terminal screen.

See the [user guide](https://github.com/pelletiermaxime/ferrydock#readme) for
setup, keyboard shortcuts and troubleshooting.
