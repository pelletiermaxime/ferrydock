FerryDock 0.4.1 fixes AppImage startup on Linux desktops with newer graphics drivers.

### Changes

- Fix AppImage startup failures such as **No GPU adapters found** caused by
  bundled Wayland libraries conflicting with the desktop's graphics drivers.

### Install

Download `ferrydock-0.4.1-linux-x86_64.AppImage`, make it executable, and launch
it from your desktop session:

```sh
chmod +x ferrydock-0.4.1-linux-x86_64.AppImage
./ferrydock-0.4.1-linux-x86_64.AppImage
```

If FUSE mounting is unavailable, add `--appimage-extract-and-run`.

On Ubuntu 24.04 or a compatible Debian-based distribution, you can instead
install `ferrydock_0.4.1_amd64.deb`:

```sh
sudo apt install ./ferrydock_0.4.1_amd64.deb
```

Alternatively, extract `ferrydock-0.4.1-linux-x86_64.tar.gz` and run `./ferrydock`
from the extracted directory. Its `INSTALL.txt` lists runtime dependencies.
Use the included `SHA256SUMS` to verify any of the three downloads.

### Requirements

- Linux x86-64 with glibc 2.39 or newer and a Wayland or X11/XWayland desktop.
- An installed font, the desktop's Wayland libraries, and a working Vulkan/EGL
  graphics driver stack.
- A local Docker daemon accessible by your user account. Docker Compose v2 is
  required for project controls.

See the [user guide](https://github.com/pelletiermaxime/ferrydock#readme) for
setup, keyboard shortcuts and troubleshooting.
