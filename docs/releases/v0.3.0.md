FerryDock 0.3.0 refreshes the workspace controls and makes container logs easier
to navigate.

### Changes

- Open container logs directly on the newest retained output, then follow live
  lines without watching the initial history scroll past.
- Navigate log history and long lines with visible vertical and horizontal
  scrollbars. Switching containers resets the previous scroll position.
- Inspect container configuration in a read-only JSON editor with syntax
  highlighting, line numbers, text selection, folding, and built-in search.
- Resize the container list and detail panel by dragging their divider.
- Edit search and Compose configuration fields with caret navigation, text
  selection, Unicode support, and undo. Ctrl+A selects text for replacement.
- Navigate controls with Tab and activate focused buttons with Enter or Space.
  Action buttons show loading state, while in-app notifications report
  completed operations, errors, and copied logs.

### Install

Download `ferrydock-0.3.0-linux-x86_64.AppImage`, make it executable, and launch
it from your desktop session:

```sh
chmod +x ferrydock-0.3.0-linux-x86_64.AppImage
./ferrydock-0.3.0-linux-x86_64.AppImage
```

If FUSE mounting is unavailable, add `--appimage-extract-and-run`.

On Ubuntu 24.04 or a compatible Debian-based distribution, you can instead
install `ferrydock_0.3.0_amd64.deb`:

```sh
sudo apt install ./ferrydock_0.3.0_amd64.deb
```

Alternatively, extract `ferrydock-0.3.0-linux-x86_64.tar.gz` and run `./ferrydock`
from the extracted directory. Its `INSTALL.txt` lists runtime dependencies.
Use the included `SHA256SUMS` to verify any of the three downloads.

### Requirements and limits

- Linux x86-64 with glibc 2.39 or newer and a Wayland or X11/XWayland desktop.
- An installed font and a working Vulkan/EGL graphics driver stack.
- An existing local Docker daemon accessible by your user account. Rootless
  Docker through a local Unix socket is supported; SSH and TCP/TLS connections
  remain unsupported.
- Docker Compose v2 and locally available configuration files are required for
  project controls. Start creates or starts services without building images.
- Log views support colours and basic progress editing. Use the Terminal tab
  for interactive applications that require a full terminal screen.

See the [user guide](https://github.com/pelletiermaxime/ferrydock#readme) for
setup, keyboard shortcuts and troubleshooting.
