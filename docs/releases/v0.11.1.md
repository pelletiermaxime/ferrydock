FerryDock 0.11.1 is the first packaged release of the 0.11 series, bringing quick
command access and a Networks workspace.

### Changes

- Save favorite commands for a Compose service or standalone container. Favorites
  stay associated with their Docker endpoint and target across container recreation.
- Press **Ctrl+K**, search by command, project, or service, and press **Enter** to
  launch a favorite. FerryDock opens its shell and waits until it is ready. Choose
  an instance when several replicas are running. Recent commands appear first.
- Pin favorites to their Compose project header for one-click access.
- Follow command output in **Quick runs** with clear running, completed, and failed
  states and exit codes. Hide the console while commands continue, then return to
  their output. Quick-run shells preserve your regular terminal and reuse idle
  sessions for the same container.
- Select and run favorites directly above the regular Terminal. The shell remains
  available afterward, with its directory, environment, history, and prompt intact.
- Browse Docker networks from the **Networks** sidebar or a container's **View
  networks** action. Search networks, inspect subnets and gateways, read container
  addresses and aliases, and open a connected container's details. Stopped
  containers retain their configured membership without showing an active IP.

### Downloads

Linux x86-64 downloads include an AppImage, Debian package, and tar.gz archive.
Apple Silicon Macs running macOS 15 or newer can use the DMG preview. Mac builds
remain ad hoc signed and not notarized. All downloads are covered by
`SHA256SUMS`.

See the [user guide](https://github.com/pelletiermaxime/ferrydock#readme) for
installation, keyboard shortcuts, requirements, and troubleshooting.
