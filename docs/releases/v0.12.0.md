FerryDock 0.12.0 introduces a native Windows x64 preview.

### Windows preview

- Connect to Docker Desktop running Linux containers through your selected local
  Windows Docker context. Use FerryDock's container, Compose, logs, terminal and
  resource workspaces from Windows.
- Download the portable ZIP, extract it and open **ferrydock.exe**. Settings,
  Compose associations and favorite commands are saved in `%APPDATA%\ferrydock`.
- Find the Windows download alongside Linux and macOS on the
  [FerryDock website](https://pelletiermaxime.github.io/ferrydock/).

The preview targets **Windows 10/11 x64** with Docker Desktop in **Linux
containers mode**. Docker Compose v2 and Windows-accessible Compose files are
needed for project controls. Projects started inside WSL may need a local file
association through **Configuration**. Container terminals use Bash/sh;
Windows containers and PowerShell/cmd container shells are outside this preview.

Windows builds are unsigned, so Windows may show a SmartScreen warning.
Native Windows desktop interaction and real Docker Desktop operations remain
pending hands-on verification.

### Downloads

- **Windows x64:** portable ZIP preview.
- **Linux x86-64:** AppImage, Debian package and tar.gz archive.
- **Apple Silicon macOS 15+:** DMG preview, ad hoc signed and not notarized.

All downloads are covered by `SHA256SUMS`. See the
[user guide](https://github.com/pelletiermaxime/ferrydock#readme) for installation,
requirements and troubleshooting.
