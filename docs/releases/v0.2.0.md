FerryDock 0.2.0 adds Compose project controls and combined service logs, with
responsive container and log views under heavy output.

### Changes

- Start, stop, and restart an entire Compose project from its project heading.
  Associate your project directory, Compose files in override order, environment
  files, and profiles once; FerryDock remembers them for that Docker connection.
- Watch live Compose operation output and return to the latest result, including
  errors, after switching between projects and containers. Conflicting project
  and container operations are blocked while an action is running.
- Read a project's combined logs without associating files. Each line identifies
  its service and container; filter by service, pause or resume following, copy
  the filtered output, or refresh the stream.
- Keep watching logs as services restart or containers are recreated. Use
  **Ctrl+4** from the container list to open the selected container's project logs.
- Browse busy container lists and log streams more smoothly. Log views render
  visible rows and retain up to 1,500 lines, keeping controls responsive during
  bursts of output.
- Keep saved projects accessible even when their containers are stopped or gone.

### Install

Download `ferrydock-0.2.0-linux-x86_64.AppImage`, make it executable, and launch
it from your desktop session:

```sh
chmod +x ferrydock-0.2.0-linux-x86_64.AppImage
./ferrydock-0.2.0-linux-x86_64.AppImage
```

If FUSE mounting is unavailable, add `--appimage-extract-and-run`.

On Ubuntu 24.04 or a compatible Debian-based distribution, you can instead
install `ferrydock_0.2.0_amd64.deb`:

```sh
sudo apt install ./ferrydock_0.2.0_amd64.deb
```

Alternatively, extract `ferrydock-0.2.0-linux-x86_64.tar.gz` and run `./ferrydock`
from the extracted directory. Its `INSTALL.txt` lists the runtime dependencies.
Use the included `SHA256SUMS` to verify any of the three downloads.

### Requirements and limits

- Linux x86-64 with glibc 2.39 or newer and a Wayland or X11/XWayland desktop.
- An installed font and a working Vulkan/EGL graphics driver stack.
- An existing local Docker daemon accessible by your user account. Rootless
  Docker through a local Unix socket is supported; SSH and TCP/TLS connections
  remain unsupported.
- Docker Compose v2 and locally available configuration files are required for
  project controls. Start creates or starts services without building images;
  it may pull missing images. Rebuild and Down are not available yet.
- Project streams initially load the last 200 lines per container and merge
  output as received. Pausing following pauses scrolling while collection
  continues within the 1,500-line history limit.

See the [user guide](https://github.com/pelletiermaxime/ferrydock#readme) for
project setup, keyboard shortcuts, and troubleshooting.
