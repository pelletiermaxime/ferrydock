FerryDock 0.7.0 adds an Images workspace for managing local Docker images.

### Changes

- Browse local images, search their tags, digests, or IDs, and inspect all tags
  and the full image ID in the detail panel.
- Sort the image list by name/ID, creation date, size, or container references.
  Creation dates are shown in UTC, and unavailable dates and sizes stay last.
- See which running or stopped containers use each image, and open a referenced
  container directly from the image details.
- Ctrl-click to select multiple images. Selection stays with the images through
  sorting, searching, and refreshes, with a count of selections hidden by search.
- Review single or bulk removal in a confirmation popup, including hidden
  selections. Images in use are preserved, deletion never forces Docker removal,
  and a failure does not stop the rest of the batch. Completion notifications
  report removed and failed counts; failed images remain selected.

### Downloads

Linux x86-64 downloads include an AppImage, Debian package, and tar.gz archive.
Apple Silicon Macs running macOS 15 or newer can use the DMG preview. Mac builds
remain ad hoc signed and not notarized. All downloads are covered by
`SHA256SUMS`.

See the [user guide](https://github.com/pelletiermaxime/ferrydock#readme) for
installation, keyboard shortcuts, requirements, and troubleshooting.
