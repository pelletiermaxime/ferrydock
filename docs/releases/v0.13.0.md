FerryDock 0.13.0 adds automatic Linux AppImage updates and container controls directly in the list.

### Linux AppImage updates

- Check for newer stable releases in the background and download them automatically.
  Open **Settings → Updates** to check manually or turn automatic checks and
  downloads off.
- Choose **Restart to update** when a download is ready. You can defer the restart;
  running containers stay running. Open terminal sessions close when FerryDock
  restarts, and updates wait until Docker and Compose operations finish.
- Downloads are verified against the release's SHA-256 checksum before installation.

AppImage updates preserve the original file's location and name and require a
writable installation directory. Install this version manually once to receive
future updates in the app. Debian packages and portable archives continue to
update through manual downloads.

### Container controls

- Start, stop, or restart containers directly from their rows without leaving
  the logs or terminal you are working in.
- Run favorite commands while an unrelated container operation is in progress.

### Downloads

- **Linux x86-64:** AppImage, Debian package and tar.gz archive.
- **Windows x64:** portable ZIP preview.
- **Apple Silicon macOS 15+:** DMG preview, ad hoc signed and not notarized.

All downloads are covered by `SHA256SUMS`. See the
[user guide](https://github.com/pelletiermaxime/ferrydock#readme) for installation
and requirements.
