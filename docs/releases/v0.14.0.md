FerryDock 0.14.0 adds Docker lifecycle markers to logs and collapsible resource graphs.

### Docker lifecycle markers

- See timestamped Docker markers alongside container and Compose project logs for
  starts, stops, restarts, exits, and other lifecycle changes, including actions
  from a terminal or another app.
- Completed restarts appear as one highlighted row with a Docker badge. Stop
  requests and confirmations group their related signals and process-exit details.
  Hover a marker to see the underlying Docker events, signals, and exit codes.
- Markers remain available when refreshing logs or switching views during the
  current FerryDock session. The log status warns when an interruption in the
  Docker event stream may leave gaps.

### Collapsible resource graphs

- Choose **Hide graphs** to replace the CPU and memory charts with a compact live
  summary and leave more room for logs. Choose **Show graphs** to restore them.
- Your choice stays in effect across containers and the Logs, Terminal, and
  Inspect tabs until you close FerryDock.

### Downloads

- **Linux x86-64:** AppImage, Debian package and tar.gz archive.
- **Windows x64:** portable ZIP preview.
- **Apple Silicon macOS 15+:** DMG preview, ad hoc signed and not notarized.

All downloads are covered by `SHA256SUMS`. See the
[user guide](https://github.com/pelletiermaxime/ferrydock#readme) for installation
and requirements.
