FerryDock 0.1.1 adds a portable AppImage download for Linux x86-64.

### Changes

- Run FerryDock without installing a package using the new AppImage, which
  bundles its application libraries and includes a FerryDock icon.
- Debian packages and compressed binary archives remain available.
- Verify any of the three downloads using the included `SHA256SUMS` file.

### Install

Download `ferrydock-0.1.1-linux-x86_64.AppImage`, make it executable, and launch
it from your desktop session:

```sh
chmod +x ferrydock-0.1.1-linux-x86_64.AppImage
./ferrydock-0.1.1-linux-x86_64.AppImage
```

If FUSE mounting is unavailable, add `--appimage-extract-and-run`.

On Ubuntu 24.04 or a compatible Debian-based distribution, you can instead
install `ferrydock_0.1.1_amd64.deb`:

```sh
sudo apt install ./ferrydock_0.1.1_amd64.deb
```

Launch **FerryDock** from your applications menu or run `ferrydock` from a desktop
terminal. The Debian package installs its runtime library dependencies.

Alternatively, extract `ferrydock-0.1.1-linux-x86_64.tar.gz` and run `./ferrydock`
from the extracted directory. Its `INSTALL.txt` lists the runtime dependencies.

### Requirements

- Linux x86-64 with glibc 2.39 or newer and a Wayland or X11/XWayland desktop.
- An installed font and a working Vulkan/EGL graphics driver stack.
- An existing local Docker daemon accessible by your user account. Rootless
  Docker through a local Unix socket is supported; SSH and TCP/TLS connections
  remain unsupported.

See the [user guide](https://github.com/pelletiermaxime/ferrydock#readme) for
keyboard shortcuts and troubleshooting.
