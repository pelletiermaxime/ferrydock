FerryDock 0.9.0 adds local image layer analysis to help understand image contents
and find opportunities to reduce image size.

### Changes

- Open the new **Analysis** tab in image details, or press **Ctrl+4**, and choose
  **Analyze image** to inspect the selected local Docker image.
- Browse build instructions and an expandable file tree for each layer, with
  added, replaced, and deleted paths. File payloads use MiB, and metadata-only
  instructions are labelled explicitly.
- Read the **Findings** view for the largest files in the final image and
  estimated waste from file payloads replaced or removed in later layers.
  The summary shows unpacked payload size, estimated waste, and efficiency;
  empty images show efficiency as unavailable.
- Cancel an analysis in progress or choose **Reanalyze** to read the image
  again. Analysis runs in the background, retains its report across image tabs,
  and shows explicit errors for unsupported images or analysis limits.

Waste estimates exclude archive overhead and duplicate-content scanning, and
do not measure the Docker disk space that image removal would recover.

### Downloads

Linux x86-64 downloads include an AppImage, Debian package, and tar.gz archive.
Apple Silicon Macs running macOS 15 or newer can use the DMG preview. Mac builds
remain ad hoc signed and not notarized. All downloads are covered by
`SHA256SUMS`.

See the [user guide](https://github.com/pelletiermaxime/ferrydock#readme) for
installation, keyboard shortcuts, requirements, and troubleshooting.
