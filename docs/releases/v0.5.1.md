FerryDock 0.5.1 adds a macOS download for Apple Silicon Macs.

### Changes

- Install FerryDock on Apple Silicon Macs running macOS 15 or newer with a
  drag-and-drop DMG. The Mac download is an early preview.
- Launch from Applications or Finder using your existing local Docker context.
  FerryDock finds Docker Desktop and Homebrew installations without requiring
  a launch from Terminal, and uses a system monospace font for Mac logs and
  container terminals.

### Install on macOS

Download `ferrydock-0.5.1-macos-arm64.dmg`, open it, and drag **FerryDock.app**
into **Applications**. Start Docker Desktop or another Docker daemon with a
local Unix socket context, then launch FerryDock. Docker Compose v2 is needed
for project controls. Intel Mac packages are not provided.

This build is **ad hoc signed and not notarized**. If macOS blocks the first
launch, try opening FerryDock, then use **System Settings → Privacy & Security
→ Open Anyway** and confirm **Open**. See
[Apple's instructions](https://support.apple.com/102445).

### Install on Linux

Download `ferrydock-0.5.1-linux-x86_64.AppImage`, make it executable, and launch
it from your desktop session:

```sh
chmod +x ferrydock-0.5.1-linux-x86_64.AppImage
./ferrydock-0.5.1-linux-x86_64.AppImage
```

If FUSE mounting is unavailable, add `--appimage-extract-and-run`. On Ubuntu
24.04 or a compatible Debian-based distribution, you can instead install
`ferrydock_0.5.1_amd64.deb`. A `ferrydock-0.5.1-linux-x86_64.tar.gz` archive is
also available. Linux packages require glibc 2.39 or newer, Wayland or
X11/XWayland, a working graphics driver, and access to a local Docker daemon.

### Verify downloads

`SHA256SUMS` covers all four packages. On macOS, run
`shasum -a 256 <downloaded-file>` and compare the result with its entry in
`SHA256SUMS`. On Linux, use `sha256sum`.

See the [user guide](https://github.com/pelletiermaxime/ferrydock#readme) for
setup, keyboard shortcuts, and troubleshooting.
